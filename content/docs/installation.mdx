## Desktop app

Download the build for your platform from the
[latest release](https://github.com/actovia-ai/actovia/releases/latest):

| Platform              | File                                           |
| --------------------- | ---------------------------------------------- |
| macOS (Apple silicon) | `Actovia-<version>-arm64.dmg`, or the `.zip`   |
| Windows               | `Actovia-<version>.Setup.exe`                  |
| Linux                 | `actovia_<version>_amd64.deb`, `actovia-<version>-1.x86_64.rpm` |
| iPhone                | [Download from the App Store](https://apps.apple.com/us/app/actovia/id6824829679) |

## iPhone app

[Download Actovia for iPhone from the App Store](https://apps.apple.com/us/app/actovia/id6824829679).
It pairs with Actovia on your computer and works with the same chats.

## Updates

On Windows the app updates itself. On macOS it checks for a new version at
launch and when you ask (**Settings → About**). On Linux, install the new
package from the release page.

## CLI

The CLI runs on [Bun](https://bun.sh) 1.3 or later:

```bash
npm install -g @actovia-ai/cli
# or try it without installing
bunx @actovia-ai/cli --help
```

Without Bun, download the standalone binary for your platform from the
[CLI's latest release](https://github.com/actovia-ai/cli/releases/latest):
`actovia-darwin-arm64`, `actovia-darwin-x64`, `actovia-linux-arm64`,
`actovia-linux-x64` or `actovia-windows-x64.exe`.

Either way, `actovia update` keeps it current — see [the CLI](/docs/cli).
