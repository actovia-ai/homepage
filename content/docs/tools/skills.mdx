A skill is a folder of instructions (and sometimes scripts) that teaches the
model how to do one kind of task well — write a changelog, fill a PDF form,
follow a house style. Actovia's skills come from
[skills.sh](https://skills.sh), the open Agent Skills registry.

Open **Settings → Skills Market**.

## Discover

Search by name or owner, or browse the leaderboards: **All time**, **Trending
(24h)** and **Hot**. **Curated** lists the registry's publishers with every skill
each maintains, its featured pick marked. Skills from the same repository fold
behind **+N more**.

## A skill's page

Each skill shows its **Security audit** (how many independent checks passed),
its **README**, its bundled files, and the command to install it from a
terminal with the [Actovia CLI](/docs/cli). **Install** puts it in
`~/.actovia/skills/`, which the CLI shares — a skill installed by either shows
up in both.

## Installed

The **Installed** tab lists your skills with a switch each (**Active**) and
**Uninstall**. Active skills are listed for the model by name and a line of
description; it reads a skill's full instructions only when your request
matches it, so having many installed costs nothing until one is used.
[Philharmonic](/docs/agents/philharmonic) employees can be given skills of
their own.
