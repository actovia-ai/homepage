The same list is in **Settings → Keyboard Shortcuts**. On Windows and Linux,
read Ctrl for ⌘.

| Shortcut | Action                                                  |
| -------- | ------------------------------------------------------- |
| ⌘N       | New chat                                                |
| ⌘,       | Open settings                                           |
| ⌘[       | Back                                                    |
| ⌘]       | Forward                                                 |
| ⌘B       | Toggle sidebar                                          |
| ⌘L       | Lock now                                                |
| ⌘W       | Close chat                                              |
| ⌘⇧E      | Focus chat input                                        |
| Enter    | Send message                                            |
| ⇧Enter   | New line                                                |
| ⌘F       | Find in page                                            |
| Esc      | Close find bar                                          |
| ⌘⇧F      | Search chat history                                     |
| ⌘⇧R      | Force refresh page                                      |
| ⌘⌥I      | Toggle developer tools                                  |
| ⌥⇧⎋      | Stop a [Computer Use](/docs/tools/computer-use) session |

**File → New Chat**, **Settings…** and **Lock Now** in the menu bar work from
anywhere in the app, Philharmonic and Settings included.
