## actovia logs

Print the desktop app's log (Settings → Logger), oldest first

```bash
actovia logs [options]
```

| Option | Description |
| --- | --- |
| `-n, --lines <n>` | how many of the newest lines (at most 500) |
| `-f, --follow` | keep printing new lines as they come |
| `--level <level>` | that level and above: debug, info, warn, error |
| `--scope <name>` | one scope only, e.g. app or kernel |
| `--trace <id>` | one trace only (a request, a job) |
| `-q, --query <words>` | the Logger search syntax: words, -word, scope:, trace: |
| `--date <YYYY-MM-DD>` | another day's log |
| `--json` | one JSON record per line |
