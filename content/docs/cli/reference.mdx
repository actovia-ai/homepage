Every command takes `-h, --help`; `actovia -V` prints the version.

## actovia open

Launch the Actovia desktop app

```bash
actovia open
```

## actovia update

Update the Actovia CLI to the newest version

```bash
actovia update [options]
```

| Option | Description |
| --- | --- |
| `--check` | only report whether an update is available, install nothing |

## actovia skills

Browse and manage skills.sh skills

```bash
actovia skills
```

## actovia skills search

Search skills.sh

```bash
actovia skills search [options] <query>
```

| Option | Description |
| --- | --- |
| `--json` | output JSON instead of a formatted list |

## actovia skills install

Install a skill by id (e.g. vercel-labs/skills/find-skills)

```bash
actovia skills install [options] <id>
```

| Option | Description |
| --- | --- |
| `--json` | output JSON instead of a formatted message |

## actovia skills list

List installed skills

```bash
actovia skills list [options]
```

| Option | Description |
| --- | --- |
| `--json` | output JSON instead of a formatted list |

## actovia skills uninstall

Uninstall a skill

```bash
actovia skills uninstall [options] <slug>
```

| Option | Description |
| --- | --- |
| `--json` | output JSON instead of a formatted message |

## actovia pair

Pair a phone with the Actovia running on this machine (shows a QR code; asks for the app-lock PIN)

```bash
actovia pair [options]
```

| Option | Description |
| --- | --- |
| `--invert` | draw the QR code for a light terminal background |

## actovia devices

List the phones paired with this machine's Actovia (asks for the app-lock PIN)

```bash
actovia devices [options]
```

| Option | Description |
| --- | --- |
| `--json` | machine-readable output |

## actovia devices revoke

Unpair a device: it can no longer reach this computer

```bash
actovia devices revoke <id>
```
