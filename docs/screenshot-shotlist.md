# Screenshot shot list

Every screenshot slot in the docs (`content/docs/**/*.mdx`, the `<Screenshot>` component in `components/screenshot.tsx`), plus the App Store Connect assets for the iPhone app. Generated from the MDX on 2026-10-21; re-check the ids with `grep -rho 'id="[^"]*"' content/docs` after editing pages.

## How to fill a slot

1. Capture at 2x (desktop: a 1440×900 window → 2880×1800; iPhone: the device or Simulator's native size, see the App Store section).
2. Save as `public/docs/shots/<id>.png` (for a slot marked `either`, one capture in whichever scheme looks best).
3. Add `src="/docs/shots/<id>.png"` to that `<Screenshot>` — the dashed placeholder becomes the image and the brief becomes its caption. Rewrite the caption as a caption if needed.

Ground rules for every capture: a demo data directory (`ACTOVIA_HOME=~/actovia-shots`, never your real `~/.actovia` — and quit the main app first, only one Actovia at a time); a fictional persona for memories, names and chats; dummy keys/configs where a secret path is shown (`~/.ssh/config` with fake contents); no real email, phone, location or health data you would not publish; English UI; clean menu bar (Bartender off, 9:41 on iOS via the Simulator's status-bar override); the default Neutral tone unless the slot says otherwise.

“Surfaces” says where else the capture can go: **homepage** = the marketing site (its own slots live in `app/_lib/shots.ts` — the mapping is below), **App Store** = App Store Connect.

## App Store Connect (iPhone app)

Checked against Apple's _Screenshot specifications_, _App preview specifications_, _App information_ and _Platform version information_ pages (developer.apple.com/help/app-store-connect/reference/app-information/…) on 2026-10-21.

### Screenshots — rules

- 1 to **10 screenshots per display size** (and per localization), `.png` / `.jpg` / `.jpeg`, **no alpha channel or transparency** (flatten Simulator PNGs before uploading: `sips -s format jpeg` or export without alpha).
- Only the largest required size of each family has to be uploaded when the UI is the same across sizes; smaller sizes are scaled down from it.

| Display (App Store Connect name)               | Status                                                                                   | Portrait px                           | Capture on                                                                    |
